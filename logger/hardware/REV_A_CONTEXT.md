The design reuses the working keyless (hondaPico) circuitry by default (buck,
protection, RS-485, connector family), adding the logger's inputs, SD, and
the ignition-qualified power hold and independent cutoff.

## What is on the board

| Block | Rev A |
|---|---|
| Board connector | **J1, JAE IL-AG5-14P-D3L2-A** (2.5 mm, 2 rows, right-angle, board guides; footprint generated by `kicad/tools/gen_fp_ilag5.py`). 1 RS-485 A, 2 bus GND (PGND), 3 B2 VSS, 4 B1 tach, 5 B11, 6 BATT_IN / 7 RS-485 B, 8 spare, 9 C11 fuel, 10 AGND (B16), 11 spare, 12 spare, 13 C14 brake, 14 PGND |
| Entry protection | F1 1 A, DREV SB360 reverse block, **1.5KE20A** clamp (sustained P12 ≤17.1 V; see DECISIONS D-OVERVOLT-04) |
| Main supply | QP IPD50P04P4L-11 high-side switch → LM2678T-5.0 buck → B5 (as keyless) |
| Always-on A5 | TPS70950 behind R_AON 820 Ω + BZX55C22 second-stage clamp (≤28 V at its input) |
| Power hold / cutoff | Qualified IGN on GP5, HOLD on GP6, independent 2048 s cutoff (clock, counters, latch) |
| Vehicle inputs | Fitted dividers and clamps carried forward unchanged; B2 (VSS) through an **ASSR-601JV** solid-state relay enabled by GP7 + hardware power-good |
| RS-485 | Keyless circuit: MAX3485 in a DIP-8 socket, GP8 TX / GP9 RX / GP10 DE+RE with 10 k pulldown; 390 Ω bias and 120 Ω termination each on a jumper, open by default |
| Grounds | AGND and PGND join only inside the Pico module; don't add a board-level bond. B16 is a sense reference, never a return |
| Other | SD module header (J5), spare GP13 + switched power (J3), RUN/GND reset (J4), HOLD link, test points |

Envelope: 80 × 120 mm, no enclosure. The board file
[accord-logger.kicad_pcb](kicad/accord-logger.kicad_pcb) has the outline (2 mm
corner radii) and four unplated M3 holes 4 mm in from each edge, made by
`kicad/tools/gen_board_outline.py`; parts come in with "Update PCB from
Schematic". Courtyard
allowance 1.90× after the surface-mount conversion (D-SMD-09) (`kicad/validation/courtyard_study.csv`).

## Fitted logger baseline (breadboard, in the car today)

The detailed physical authority is [AS_BUILT.md](as-built/AS_BUILT.md).

| Block | Fitted state |
|---|---|
| VSS | B2 → 22k/33k → GP2; upper 1N5819 clamp to Pico 3V3 |
| Tach / brake | B1 / C14 → 22k/6.8k → GP3 / GP4; upper 1N5819 clamps |
| Fuel | C11 → 7.5k/4.7k → GP26; 1k series, 1 µF and two 1N5819 clamps |
| Supply sensing | B11 → 22k/4.7k → GP27; same ADC protection/filter |
| IGN | B11 via inline fuse, 1N5819, 2.2k into opto LED; collector → GP5 |
| SD | SPI0 GP16/17/18/19 on Pico 3V3 |
| Power | Manual external buck; no automatic cutoff |

Parked measurements (owner, settled, don't re-ask): B2 open **4.669 V**,
loaded **4.140 V**, divider junction **1.042 V**, unpowered 3V3 **0.883 V**,
so about **140.8 µA** B2 draw with about 109 µA back-fed into the Pico. B1 and
C11 read 0 V, and C14 and B11 are dead with the key out. B2 is the only branch
live while parked, hence the relay.

## Firmware

Public source is **0.8.1-lra05-dev**, manual power by default
(`LOGGER_POWER_QUALIFIED=0`). The opt-in qualified shutdown exists but is not
physically accepted. Before the board runs autonomously, firmware needs the
GP7 isolation enable and the isolate-then-release shutdown order in
`LRA12_HANDOFF.md` §5.4. Configuration: [../NEXT_AGENT.md](../NEXT_AGENT.md).
